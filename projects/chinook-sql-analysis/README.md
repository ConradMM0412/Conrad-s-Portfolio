# Chinook SQL Analysis

SQL project developed using the Chinook database to analyze sales, customers, genres, artists, and purchasing behavior.

## Project Overview

This project demonstrates SQL skills through a series of analytical queries using Microsoft SQL Server Management Studio.

The analysis includes sales performance, customer spending, country-level sales, genre performance, artist performance, yearly sales trends, subqueries, and Common Table Expressions (CTEs).

## Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

## Skills Demonstrated

- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- JOIN
- SUM
- AVG
- COUNT
- Subqueries
- Common Table Expressions (CTEs)

## Queries

1. Total Sales
2. Sales by Country
3. Top Customers by Spending
4. Top Genres by Sales
5. Sales by Year
6. Top Artists by Sales
7. Customers Above Average Spending
8. Customer Spending Analysis using a CTE

## Database

This project uses the Chinook sample database, which represents a digital media store with customers, invoices, tracks, albums, artists, and genres.
